# Baseline Security Assessment

Date: 2026-09-07

## Current Level

Approx. **Lv.0.7 — Security Beginner**

## Linux

- Can explain `pwd`, `ls`, `cd`.
- Need to learn Linux directory structure, permissions, `sudo`, `chmod`, users/groups, processes.

## Network

- Has basic intuition for IP and TCP/UDP.
- Needs to separate:
  - DNS vs Router
  - IP vs Port
  - TCP vs HTTP
  - IP/TCP/HTTP headers

## HTTP / Web

Priority learning area.

Need to learn:

- HTTP Request / Response
- GET / POST
- Header / Body
- Cookie / Session
- Authentication / Authorization

## Security

- Has a rough idea of SQL Injection.
- Understands why plaintext password storage is dangerous.
- Needs to learn XSS, Access Control, authentication/authorization flaws.

## Reassessment Goals

After 4 weeks, explain:

1. DNS vs Router
2. TCP vs HTTP
3. IP vs Port
4. Cookie vs Session
5. HTTP Request structure
6. Authentication vs Authorization
7. Root cause and mitigation of SQL Injection and XSS
