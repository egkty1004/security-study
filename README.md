# Security Study

정보보안 기초부터 실무형 역량까지 단계적으로 쌓기 위한 학습 저장소입니다.

## Goals

- Linux / OS 기초
- Network 기초
- HTTP / Web 구조 이해
- Web Security 실습
- Dreamhack / PortSwigger Write-up
- 장기적으로 Application Security, Security Engineering, AI Security로 확장

## 4-Week Roadmap

| Week | Topic | Main Goal |
|---|---|---|
| 1 | Linux + OS | 파일, 사용자, 권한, 프로세스 이해 |
| 2 | Network | IP, Port, TCP/UDP, DNS, Router 구분 |
| 3 | HTTP / Web | Request/Response, Cookie/Session 분석 |
| 4 | Web Security | SQLi, XSS, Access Control 첫 실습 |

## Study Rule

각 실습은 가능하면 다음을 남깁니다.

1. What I learned
2. What I tested
3. Security point
4. Why it is vulnerable
5. Attack principle
6. Defense / mitigation
7. What I still do not understand

> Notion은 학습 과정과 회고를, GitHub는 기술 결과물과 분석 기록을 중심으로 관리합니다.
